PTM Connection Test

Opens many separate Firebase connections from this one page, each acting like a parent's phone with the queue page open. It shows how many can stay connected at the same time, so you can see the Spark plan's 100-connection limit (or confirm it is gone after upgrading to Blaze).

Read before running: these connections count toward your real limit. Do not run this during a real PTM, or real parents may be refused. The test only reads (it never writes or joins a queue), so it adds no fake students. Close the page or press Stop to release every connection.

1. Settings

“Connect per second” of 0 connects everyone at the same instant (a worst case). Leave Room ID empty to auto-pick one room; each fake parent then also listens to that room's live number, like the real page.

How to read the result

  1. All connected (e.g. 150 of 150): no connection limit at that size. On Blaze this is what you should see.
  2. Stops at about 100, the rest red: the Spark limit of 100 simultaneous connections.
  3. Amber squares: connections that were made and then lost. Firebase retries these by itself.
